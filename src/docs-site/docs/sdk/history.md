# SDK History

The origin of this SDK is [Scalable Objects Persistence (SOP)](https://github.com/sharedcode/sop).

SOP is the open source foundation behind the SDK. The public SOP repository is released under the MIT License and remains the long-term community base for the architecture, runtime, and data platform concepts that the SDK builds on.

## Why the SDK exists separately

The SDK carries the newest working and stable source code for subscribers.

The public SOP repository continues to receive the architecture after it has had more time to mature in production and stabilize across real-world usage. In practice, that means the community version is intentionally slightly older than the subscriber SDK source.

This is mainly a release-maturity decision, not a change in technical direction. New features need time to solidify before they are pushed into the public SOP line. Because of that stabilization window, public SOP updates for newer SDK capabilities are typically at least six months behind the subscriber source release.

## Source availability model

- SOP open source repository: community-accessible and MIT licensed
- SDK subscriber source: latest working, stable version available as part of the monthly subscription plan
- Public SOP updates: follow after features have matured enough for broader open-source release

This model gives subscribers earlier access to the latest stable SDK implementation, while the broader SOP community continues to receive a more time-tested public release.
