# Store Management

Stores in Northstar AI let you inspect and manage structured data visually without leaving the product. They are the right choice when you want to browse records, test queries, or debug data issues quickly.

## When to use Stores

Use Stores when you want to:

- browse data in a database-like view
- inspect records and structure visually
- run simple filters or ad-hoc queries
- debug data issues during development
- prototype data shapes before writing full application logic

## Common workflows

### Browse and inspect data
Open a store to review its contents, search records, and understand how your data is organized.

### Query and analyze
Run simple queries, apply filters, and inspect results from the UI without writing a full script.

### Manage data during development
Add, edit, or remove records while you are iterating on an application or fixing a bug.

## Best practices

- Use Stores for quick inspection and debugging.
- Keep your data model clear before scaling up automation.
- Use Spaces for semantic knowledge and retrieval, and Stores for structured data.

## Stores vs Spaces

- **Stores** are for structured data and database-style management.
- **Spaces** are for semantic knowledge organization and AI retrieval.

This separation helps you choose the right tool for the task at hand.
