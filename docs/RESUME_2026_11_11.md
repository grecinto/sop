# Resume Point - November 11, 2026

**Status:** Implementation gaps in daemon service unwrapping, workspace intake pre-seeding, repo hint normalization, and `/workspace` slash command controls are fixed. Automated daemon and agent test suites pass; live provider and clean-install validation remain.

## Where We Left Off

- Northstar AI Ask remains the outer controller. AI Studio has one production Send path, and Ask delegates bounded coding tasks to the selected backend.
- `workflow_backend` selects `cline` (default), `continue`, or `native`. Aliases (`daemon`, `shell`, `in-house`) normalize cleanly to `native`. Cline and Continue fail closed when unavailable; there is no silent fallback.
- **Service Unwrapping & Backend Injection Fixed:** `injectIDEWorkerBackend`, `injectShellSessionManager`, and `continueTeamPracticeAgent` now inspect `service.RegisteredAgents()` and support both `"copilot"` and `"sql_core"` (the sub-agent ID used in `copilot_pipeline.json`). This ensures the configured IDE worker backend (Cline) and shell manager are reliably injected into the active `CopilotAgent` across service wrappers and clones.
- **Workspace Scope Intake Fixed:** The daemon no longer pre-seeds `payload.Variables["workspace_root"]` or `payload.ActiveRepo` with the daemon process CWD (`daemonCwd`). `working_dir` continues to be maintained for shell sessions, while `workspace_root` remains owned by Ask until established.
- **Clarification Workspace Extraction Fixed:** When Ask asks the user for the repository or working directory and the user clarifies (e.g. answering "current", "here", or a directory path), `restoreCodingWorkspaceRoot` now extracts the answer from the resolved clarification, normalizes it via `repoPathFromContext`, and stores it in conversation thread memory and `payload.Variables["workspace_root"]`.
- **Repo Hint Normalization Fixed:** `normalizeRepoHint` now recognizes `"current"`, `"here"`, and `"pwd"`, allowing natural conversational answers like "current" to map to the enclosing Git root.
- **Workspace Scope Slash Commands:** `/workspace <path>` and `/repo <path>` now set or switch the active coding workspace in conversation STM thread memory and session variables. `/workspace clear` clears the active scope.
- **Composite Backend Transparency:** `compositeIDEWorkerBackend` now transparently implements `OwnsCodingWorkflow()` and `CodingCapabilityName()`.
- **Absolute Workspace Root Normalization:** `clineWorkerBackend.ExecuteTask` and `clineSDKHostManager.Run` guarantee `req.WorkspaceRoot` is resolved to an absolute path before snapshotting and host invocation.
- Automated daemon, agent, and SDK host tests pass cleanly.
