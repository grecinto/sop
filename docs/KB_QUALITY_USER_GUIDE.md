# KB Quality User Guide

## What is Space Quality?

Space Quality is the system's way of measuring how useful a Space is for a given coding task. It combines:

- validation outcomes
- user feedback
- historical success rates
- compliance with KB rules

When the system is confident, it selects the best Space automatically. When it is uncertain, it can suggest alternatives or ask for a manual choice.

## How to use the feature

### Feedback buttons

After a generation, you may see feedback buttons such as 👍 and 👎. Use these to tell the system whether the result was useful.

### Explanations

When explanations are enabled, the assistant can show why a result was selected and which rules were applied. This helps you understand the reasoning without moving away from the conversation.

### Refinement controls

Each message can expose refinement actions such as:

- Apply Stricter
- Try Different Space
- Disable Space for this session

These controls are designed to help you steer the workflow without re-running the entire task from scratch.

## Reading the dashboard

Open the Quality Dashboard at /kb-quality to review:

- Space usage frequency
- success rates
- recent feedback
- validation performance

## Tips

- Give feedback often so the system learns faster
- Start with a small set of focused Spaces
- Use the refinement controls when the first result is close but not quite right
